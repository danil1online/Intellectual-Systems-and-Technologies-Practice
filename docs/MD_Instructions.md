# Справочник по разметке Markdown

Markdown (MD) — лёгкий язык разметки, который позволяет форматировать текст с помощью простых символов.
Все файлы с расширением `.md` автоматически отображаются в виде отформатированного текста в GitLab,
JupyterLab и Nextcloud.

---

## 1. Заголовки

Создаются с помощью символа `#`. Количество решёток определяет уровень заголовка (от 1 до 6):

```markdown
# Заголовок 1 уровня (H1)
## Заголовок 2 уровня (H2)
### Заголовок 3 уровня (H3)
#### Заголовок 4 уровня (H4)
##### Заголовок 5 уровня (H5)
###### Заголовок 6 уровня (H6)
```

Результат:

# Заголовок 1 уровня (H1)

## Заголовок 2 уровня (H2)

### Заголовок 3 уровня (H3)

## 2. Форматирование текста

### Полужирный текст

Оберните текст двумя звёздочками `**` или двумя подчёркиваниями `__`:

```markdown
**Полужирный текст**
__Полужирный текст__
```

Результат: **Полужирный текст**

### Курсив

Оберните текст одной звёздочкой `*` или одним подчёркиванием `_`:

```markdown
*Курсив*
_Курсив_
```

Результат: *Курсив*

### Полужирный курсив

Оберните текст тремя звёздочками `***` или тремя подчёркиваниями `___`:

```markdown
***Полужирный курсив***
```

Результат: ***Полужирный курсив***

### Зачёркнутый текст

Оберните текст двумя тире `--`:

```markdown
--зачёркнутый текст--
```

Результат: --зачёркнутый текст--

### Выделение кодом (inline)

Оберните текст обратными апострофами `` ` ``:

```markdown
Текст с `моноширинным` выделением
```

Результат: Текст с `моноширинным` выделением

## 3. Списки

### Маркированный список

Используйте `-`, `*` или `+`:

```markdown
- Первый пункт
- Второй пункт
- Третий пункт
```

Результат:

- Первый пункт
- Второй пункт
- Третий пункт

### Нумерованный список

Используйте цифры с точкой:

```markdown
1. Первый пункт
2. Второй пункт
3. Третий пункт
```

Результат:

1. Первый пункт
2. Второй пункт
3. Третий пункт

### Вложенные списки

Используйте отступы (2 или 4 пробела):

```markdown
- Пункт 1
  - Подпункт 1.1
  - Подпункт 1.2
- Пункт 2
  1. Подпункт 2.1
  2. Подпункт 2.2
```

Результат:

- Пункт 1
  - Подпункт 1.1
  - Подпункт 1.2
- Пункт 2
  1. Подпункт 2.1
  2. Подпункт 2.2

### Чек-листы (списки с флажками)

```markdown
- [x] Выполнено
- [ ] Не выполнено
- [ ] В процессе
```

Результат:

- [x] Выполнено
- [ ] Не выполнено
- [ ] В процессе

## 4. Ссылки

### Гиперссылка

```markdown
[Текст ссылки](https://example.com)
```

Результат: [Текст ссылки](https://example.com)

### Ссылка с подсказкой

```markdown
[Текст ссылки](https://example.com "Подсказка при наведении")
```

### Ссылка на файл в том же репозитории

```markdown
[Справочник по Markdown](./MD_Instructions.md)
[Практическая 1](./Pr_1.md)
```

### Ссылка на раздел внутри файла

```markdown
[Перейти к заголовку](#форматирование-текста)
```

## 6. Блоки кода

### Код с подсветкой синтаксиса

Укажите язык после первых обратных апострофов:

````markdown
```python
print("Hello, World!")
```

```bash
git clone https://gitlab.example.com/user/repo.git
```

```javascript
console.log("Hello");
```
````

### Блок кода без подсветки

Используйте 4 пробела в начале каждой строки:

```
    def hello():
        print("Hello, World!")
```

## 7. Цитаты

Используйте символ `>`:

```markdown
> Это цитата.
> 
> Цитата может состоять из нескольких строк.

> Цитата с автором:
> 
> — Кто-то, 2024
```

Результат:

> Это цитата.
> 
> Цитата может состоять из нескольких строк.

> Цитата с автором:
> 
> — Кто-то, 2024

```markdown
|-------------|-------------|-------------|
| Ячейка 1    | Ячейка 2    | Ячейка 3    |
| Ячейка 4    | Ячейка 5    | Ячейка 6    |
```

Результат:

| Заголовок 1 | Заголовок 2 | Заголовок 3 |
|-------------|-------------|-------------|
| Ячейка 1    | Ячейка 2    | Ячейка 3    |
| Ячейка 4    | Ячейка 5    | Ячейка 6    |

```markdown

```

Результат:

| Левый | Центр | Правый |
|:------|:-----:|-------:|
| 1     |   2   |     3  |

## 10. Экранирование

Если нужно вывести символ разметки как обычный текст, используйте обратный слэш `\`:

```markdown
\*Это не курсив\*
\#Это не заголовок
```

Результат: \*Это не курсив\*

## 13. Практические советы

### Структура отчёта в Markdown

Рекомендуемая структура файла отчёта:

```markdown
# Практическая работа №X: Название работы

## Цель работы
Описание цели.

## Ход работы
### Шаг 1: ...
Описание и скриншоты.

### Шаг 2: ...
Описание и скриншоты.

## Результаты
Таблицы, графики, выводы.

## Выводы
Что было изучено, что получилось.

## Ответы на контрольные вопросы
1. Вопрос 1
   Ответ: ...
```

### Вставка скриншотов

1. Сохраните скриншот как PNG или JPG
2. Поместите файл рядом с `.md` файлом в папку `images/`
3. Вставьте в Markdown: `![Описание](images/screen.png)`

### Именование файлов

- Используйте английские буквы, цифры, дефисы
- Без пробелов: `my-report.md` вместо `my report.md`
- Префикс с номером: `Pr_1_setup.md`
