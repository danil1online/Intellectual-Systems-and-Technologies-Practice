## 📚 Краткая теоретическая информация

### Архитектура Langflow
Langflow — low-code платформа для визуального конструирования AI-систем. Базовая единица — **компонент** (блок) с входными и выходными портами. Компоненты соединяются **рёбрами** в граф (flow), который выполняется как единое целое. Основные категории компонентов:

- **Inputs & Outputs** — `Chat Input` (ввод диалога), `Chat Output` (вывод ответа);
- **Models & Agents** — языковые модели (`OpenAI`, Ollama и др.), `Prompt Template` (шаблон промпта с переменными в фигурных скобках);
- **Data** — загрузка файлов, работы с базами данных;
- **Vector Stores / Embeddings** — векторные хранилища и модели эмбеддингов (используются в следующих работах).

### OpenAI-совместимый API и llama.cpp
`llama-server` из проекта `llama.cpp` предоставляет HTTP-интерфейс, совместимый с API OpenAI: маршруты `/v1/chat/completions`, `/v1/models`. Поэтому любой компонент «OpenAI» в Langflow можно направить на локальный сервер, указав **Base URL** вида `http://<host>:8080/v1` (суффикс `/v1` обязателен) и произвольный API-ключ.

### Параметры генерации
- **Temperature** — температура сэмплирования: делит логиты модели до softmax; малые значения → детерминированный ответ, большие → разнообразнее, но менее предсказуемый.
- **System Message** — системная инструкция: задаёт роль и правила поведения модели на весь диалог.
- **Stream** — потоковая передача ответа (SSE) по мере генерации токенов.

## 🛠️ Порядок выполнения работы

### Шаг 1. Авторизация и создание проекта
1. Откройте браузер и перейдите по адресу Langflow (`http://<IP_лаборатории>:7860`), авторизуйтесь выданными учётными данными.
2. Нажмите **New Flow** → **Blank Flow**, переименуйте проект в `Практическая 29 - Базовый Чат-бот`.

### Шаг 2. Размещение компонентов на холсте
Перетащите из боковой панели:
1. **Inputs & Outputs → Chat Input**;
2. **Inputs & Outputs → Chat Output**;
3. **Models & Agents → Prompt Template**;
4. **Models & Agents → OpenAI** (Language Model).

### Шаг 3. Конфигурирование компонента модели OpenAI
| Параметр | Значение |
|---|---|
| OpenAI Base URL | `http://<IP_LLM>:8080/v1` *(суффикс `/v1` обязателен)* |
| Model Name | `qwen2.5-3b-instruct-q4_k_m.gguf` |
| OpenAI API Key | `not-needed` |
| Temperature | `0.7` |
| Stream | `True` |

### Шаг 4. Настройка шаблона промпта (Prompt Template)
```text
System: Ты — квалифицированный ассистент кафедры интеллектуальных систем. Отвечай строго, четко и структурировано на русском языке.

User: {user_message}
```

### Шаг 5. Связывание компонентов (построение ребер графа)
1. `Text` (Chat Input) → `user_message` (Prompt);
2. `Prompt Text` (Prompt) → `Input Value` (OpenAI Model);
3. `Text` (OpenAI Model) → `Text` (Chat Output).

### Шаг 6. Запуск и отладка в Playground
1. Нажмите **Playground** (правый нижний угол).
2. Отправьте запрос: «Объясни кратко, что такое нейронная сеть и какова роль функции активации?».
3. Убедитесь в корректности потокового вывода текста.

### Шаг 7. Исследование параметров генерации
Выполните три запроса с одинаковым вопросом «Придумай 3 оригинальных названия для лабораторного робота-помощника» при `Temperature` = 0.1, 0.7, 1.3. Сравните степень вариативности ответов и занесите выводы в отчёт (таблица).
