## 📚 Краткая теоретическая информация  

### 📚 Введение: связь с системами поддержки принятия решений

Системы поддержки принятия решений — программные средства, которые помогают специалистам обрабатывать данные, строить прогнозы, выявлять скрытые закономерности и выбирать оптимальные варианты действий.

  - Кластеризация в СППР применяется для сегментации клиентов, выявления аномалий и создания рекомендаций.
  - Регрессия — для прогнозирования ключевых показателей (продаж, спроса, рисков).
  - Оптимизация — для подбора конфигураций, планирования и многокритериального выбора альтернатив.

1. 📚 Кластеризация в СППР
  - Задача: группировка объектов без заранее заданных меток для поддержки анализа и сегментации.
  - Метрики:
    - [Silhouette Score](https://wiki.loginom.ru/articles/cluster-silhouette-index.html): мера однородности внутри кластеров и различимости между ними,
    - [Calinski–Harabasz Index](https://permetrics.readthedocs.io/en/latest/pages/clustering/CHI.html): отношение межкластерного разброса к внутрикластерному,
    - [Davies–Bouldin Index](https://github.com/akankshadara/Davies_Bouldin_Index_KMeans): средняя похожесть каждого кластера с «наиболее похожим» другим (меньше – лучше).
2. 📚 Регрессия в СППР
  - Задача: непрерывное прогнозирование для оценки и планирования.
  - Метрики:
    - [MAE (Mean Absolute Error)](https://wiki.loginom.ru/articles/mae.html),
    - [MSE (Mean Squared Error)](https://habr.com/ru/articles/821547/),
    - [R² (коэффициент детерминации)](https://habr.com/ru/articles/821547/).
3. 📚 Оптимизация в СППР
3.1. Однокритериальная оптимизация
  - Best‐found solution — значение целевой функции
  - Скорость сходимости (число итераций / шагов до достижения порога)
  - Время выполнения
3.2. [Многокритериальная оптимизация](https://neerc.ifmo.ru/wiki/index.php?title=Задача_многокритериальной_оптимизации._Multiobjectivization)
  - Определение: одновременный учёт двух и более целей (например, стоимость vs. надёжность).
  - Парето-эффективность: решение считается Парето-оптимальным, если нельзя улучшить одну цель, не ухудшив другую.
  - Парето-фронт: набор всех Парето-оптимальных решений.
  - [Метрики оценки фронта Парето](https://cyberleninka.ru/article/n/programmnaya-sistema-pareto-rating-dlya-otsenki-kachestva-pareto-approksimatsii-v-zadache-mnogokriterialnoy-optimizatsii/viewer)
    - Hypervolume (объём гиперпрямоугольника, захватываемого фронтом)
    - Generational Distance (среднее расстояние до истинного фронта)
    - Spread / Spacing (равномерность распределения точек фронта)
    - Epsilon-индикатор (минимальное смещение фронта для покрытия эталонного)

## 🧪 Примеры

### 🧪 Пример 1. Кластеризация и метрики качества

Ниже — пример скрипта `clustering.py`: KMeans (3 кластера) на датасете Iris, расчёт трёх метрик качества кластеризации и визуализация в 2D через PCA.

```python
#!/usr/bin/env python3
# file: clustering.py

from sklearn.datasets import load_iris
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, calinski_harabasz_score, davies_bouldin_score
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

# Загрузка и подготовка данных
data = load_iris()
X = data.data

# Кластеризация
n_clusters = 3
model = KMeans(n_clusters=n_clusters, random_state=42)
labels = model.fit_predict(X)

# Расчёт метрик
sil_score = silhouette_score(X, labels)
ch_score = calinski_harabasz_score(X, labels)
db_score = davies_bouldin_score(X, labels)

print(f"Silhouette Score: {sil_score:.3f}")
print(f"Calinski–Harabasz Index: {ch_score:.3f}")
print(f"Davies–Bouldin Index: {db_score:.3f}")

# Визуализация кластеров в 2D через PCA
pca = PCA(n_components=2)
X2 = pca.fit_transform(X)
plt.scatter(X2[:,0], X2[:,1], c=labels, cmap='tab10', alpha=0.7)
plt.title("KMeans Clustering (Iris)")
plt.xlabel("PC1")
plt.ylabel("PC2")
plt.savefig("results/clustering_iris.png")
print("График сохранён в results/clustering_iris.png")
```

**📖 Что происходит в коде**

- `load_iris()` — 150 объектов × 4 числовые признаки; целевые метки (`data.target`) здесь не используются: кластеризация — задача несупервизорная.
- `KMeans(n_clusters=3, random_state=42)` — три кластера (число видов в Iris); `random_state=42` делает инициализацию воспроизводимой; `fit_predict(X)` — обучение модели и присвоение каждого объекта кластеру.
- `silhouette_score` (−1…1, выше — лучше) — насколько объект ближе к собственному кластеру, чем к ближайшему чужому; `calinski_harabasz_score` (выше — лучше) — отношение межкластерной дисперсии к внутрикластерной; `davies_bouldin_score` (ниже — лучше) — средняя «похожесть» каждого кластера на ближайший к нему чужой.
- `PCA(n_components=2)` — снижение размерности 4→2 только для визуализации; `c=labels` — цвет точки по найденному кластеру.

Запуск из командной строки:

```bash
python clustering.py
```

**📌 Ожидаемый результат**: строки `Silhouette Score: ≈0.55`, `Calinski–Harabasz Index: ≈561.6`, `Davies–Bouldin Index: ≈0.66` и `График сохранён в results/clustering_iris.png`. На диаграмме — три группы: один вид Iris почти полностью отделён, два других частично перекрываются — отсюда silhouette около 0.55, а не ближе к 1.

### 🧪 Пример 2. Регрессия и метрики

Ниже — пример скрипта `regression.py`: линейная регрессия на датасете Diabetes, метрики MAE/MSE/R² и диаграмма «фактические vs предсказанные» значения.

```python

#!/usr/bin/env python3
# file: regression.py

from sklearn.datasets import load_diabetes
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
import matplotlib.pyplot as plt

data = load_diabetes()
X, y = data.data, data.target

model = LinearRegression()
model.fit(X, y)
y_pred = model.predict(X)

mae = mean_absolute_error(y, y_pred)
mse = mean_squared_error(y, y_pred)
r2 = r2_score(y, y_pred)

print(f"MAE: {mae:.2f}, MSE: {mse:.2f}, R²: {r2:.3f}")

plt.scatter(y, y_pred, alpha=0.5)
plt.xlabel("Actual")
plt.ylabel("Predicted")
plt.title("Regression: Actual vs Predicted")
plt.savefig("results/regression_scatter.png")
print("График сохранён в results/regression_scatter.png")
```

**📖 Что происходит в коде**

- `load_diabetes()` — 442 образца × 10 признаков; цель (`data.target`) — количественный показатель, связанный с прогрессом заболевания.
- `LinearRegression().fit(X, y)` — коэффициенты подбираются методом наименьших квадратов в явном виде (градиентные итерации не нужны).
- `y_pred = model.predict(X)` — предсказание на тех же данных, на которых обучена модель (разбиение train/test не делается): метрики характеризуют качество на обучающей выборке и завышают реальную точность.
- `mean_absolute_error` — средняя ошибка по модулю (в тех же единицах, что и цель); `mean_squared_error` — средняя квадратичная (сильнее штрафует крупные ошибки); `r2_score` — доля дисперсии цели, объяснённая моделью (1 — идеально, 0 — модель не лучше среднего по выборке).
- На диаграмме каждая точка — пара (факт, прогноз): чем ближе облако к диагонали y=x, тем выше качество.

### 🧪 Пример 3. Оптимизация. Исследуемая область — сфера

Ниже — пример скрипта `optimization.py`: однокритериальная оптимизация сферической функции методом случайного поиска (10 измерений, 200 итераций) и график сходимости.

```python

#!/usr/bin/env python3
# file: optimization.py

import numpy as np
import matplotlib.pyplot as plt

def sphere(x):
    return np.sum(x**2)

def random_search(dim, iterations):
    best = float('inf')
    history = []
    for i in range(iterations):
        candidate = np.random.uniform(-5, 5, size=dim)
        value = sphere(candidate)
        if value < best:
            best = value
        history.append(best)
    return history

history = random_search(dim=10, iterations=200)
plt.plot(history)
plt.xlabel("Iteration")
plt.ylabel("Best Value")
plt.title("Random Search Convergence")
plt.savefig("results/optimization_convergence.png")
print("График сохранён в results/optimization_convergence.png")
```

**📖 Что происходит в коде**

- `sphere(x) = Σx_i²` — сферическая тестовая функция: глобальный минимум ровно в нуле, `f(0) = 0`; значение растёт с удалением от нуля.
- `random_search`: на каждой итерации генерируется новая случайная точка из куба [−5, 5]^10; `best` — наименьшее найденное к настоящему моменту значение; `history` — неувеличивающаяся последовательность «лучшее значение после i-й итерации».
- График кривой сходимости («лучшее значение vs итерация») — по его наклону судят о скорости сходимости метода.

Запуск:

```bash
python optimization.py
```

**📌 Ожидаемый результат**: строка `График сохранён в results/optimization_convergence.png`. Кривая быстро снижается в первые десятки итераций, затем выходит на плато — но заметно выше нуля: 200 случайных точек в 10 измерениях недостаточно, чтобы попасть в окрестность глобального минимума (наглядная иллюстрация «проклятия размерности»).

### 🧪 Пример 4. Оптимизация. Двухкритериальный случайный поиск с визуализацией фронта Парето

Ниже — пример скрипта `bi_objective_optimization.py`: двухкритериальный случайный поиск (2 измерения, 500 точек) и визуализация фронта Парето.

```python

#!/usr/bin/env python3
# file: bi_objective_optimization.py

import numpy as np
import matplotlib.pyplot as plt
from itertools import product

def f1(x):
    return np.sum(x**2)

def f2(x):
    return np.sum((x-2)**2)

def is_pareto(points):
    pareto = []
    for i, p in enumerate(points):
        dominated = False
        for j, q in enumerate(points):
            if all(q <= p) and any(q < p):
                dominated = True
                break
        if not dominated:
            pareto.append(p)
    return np.array(pareto)

def random_search(dim, iterations):
    results = []
    for _ in range(iterations):
        x = np.random.uniform(-5, 5, size=dim)
        results.append([f1(x), f2(x)])
    return np.array(results)

# Основной запуск
history = random_search(dim=2, iterations=500)
front = is_pareto(history)

# Визуализация
plt.scatter(history[:,0], history[:,1], alpha=0.3, label='All solutions')
plt.scatter(front[:,0], front[:,1], color='red', label='Pareto front')
plt.xlabel("f1(x) = ∑x²")
plt.ylabel("f2(x) = ∑(x–2)²")
plt.title("Bi-objective Random Search and Pareto Front")
plt.legend()
plt.savefig("results/bi_objective_pareto.png")
print("График сохранён в results/bi_objective_pareto.png")
```

**📖 Что происходит в коде**

- Две конфликтующие цели: `f1 = Σx_i²` минимальна в нуле, `f2 = Σ(x_i−2)²` — в точке x = 2: двигаясь к минимуму одной, мы отдаляемся от минимума другой.
- `random_search` генерирует 500 случайных точек из [−5, 5]² и записывает пары их целевых значений (f1, f2) — «пространство целей».
- `is_pareto`: точка доминируется, если существует другая, не хуже по всем целям и строго лучшая хотя бы по одной; функция возвращает все недоминируемые точки — фронт Парето (попарное сравнение, O(n²)).
- На графике красным выделен фронт Парето — «контур компромисса»: точки, в которых нельзя улучшить одну цель, не ухудшив другую.

Запуск:

```bash
python bi_objective_optimization.py
```

**📌 Ожидаемый результат**: строка `График сохранён в results/bi_objective_pareto.png`. Красные точки образуют дугу в левом нижнем углу облака: левый край — оптимум f1 (f1 ≈ 0, f2 ≈ 8), правый — оптимум f2 (f2 ≈ 0, f1 ≈ 8), промежуточные точки — компромиссы между целями.

### 🧪 Пример 5. Оптимизация функции Растригина

Ниже — пример скрипта `rastrigin_optimization.py`: случайный поиск на функции Растригина (2 измерения, 1000 итераций, диапазон [−5.12, 5.12]) — классической многоэкстремальной тестовой функции.

```python

#!/usr/bin/env python3
# file: rastrigin_optimization.py

import numpy as np
import matplotlib.pyplot as plt

def rastrigin(x, A=10):
    """
    Rastrigin function:
      f(x) = A * n + sum(x_i^2 - A * cos(2π x_i))
    Global minimum at x = 0, f(0) = 0.
    """
    return A * len(x) + np.sum(x**2 - A * np.cos(2 * np.pi * x))

def random_search(dim, iterations, bounds):
    best = float('inf')
    history = []
    for i in range(iterations):
        candidate = np.random.uniform(bounds[0], bounds[1], size=dim)
        value = rastrigin(candidate)
        if value < best:
            best = value
        history.append(best)
    return history

if __name__ == "__main__":
    # Параметры поиска
    dim = 2
    iterations = 1000
    bounds = (-5.12, 5.12)

    # Запуск случайного поиска
    history = random_search(dim, iterations, bounds)

    # Визуализация сходимости
    plt.figure(figsize=(6,4))
    plt.plot(history, color='blue', linewidth=1)
    plt.xlabel("Итерация")
    plt.ylabel("Лучшее значение f(x)")
    plt.title("Конвергенция случайного поиска на функции Растригина")
    plt.grid(True)
    plt.tight_layout()
    plt.savefig("results/rastrigin_convergence.png")
    print("График конвергенции сохранён в results/rastrigin_convergence.png")
```

**📖 Что происходит в коде**

- `rastrigin(x, A=10) = A·n + Σ(x_i² − A·cos(2πx_i))` — функция с «решёткой» минимумов: глобальный минимум — только в нуле (f(0) = 0), локальные — во всех целочисленных точках (f = n); косинусный член создаёт множество экстремумов.
- `random_search` — тот же «случайный поиск с запоминанием лучшего»; границы [−5.12, 5.12] — стандартный диапазон функции Растригина.
- `plt.grid(True)`, `plt.tight_layout()` — сетка и автоподгонка подписей; график — кривая сходимости «лучшее значение vs итерация».
