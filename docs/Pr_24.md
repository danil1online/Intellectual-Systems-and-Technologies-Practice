## 📚 Краткая теоретическая информация  

### 📚 Задача «Генерация изображений»

Генерация изображений подразумевает обучение модели, способной создавать новые изображения, схожие по распределению с обучающим набором. Часто используются архитектуры автокодировщиков (VAE), генеративных состязательных сетей (GAN) или диффузионных моделей. Качество работы таких моделей оценивают не только визуально, но и с помощью численных метрик.

### 📚 Inception Score (IS)

Inception Score основан на предсказаниях сети Inception v3 на сгенерированных образцах. Высокий IS достигается, если предсказания сети однозначны (низкая энтропия условного распределения) и разнообразны (высокая энтропия среднего распределения).

Формула IS:

$$
  IS = \exp\left(\mathbb{E}_{x \sim p_g}\, D_{\mathrm{KL}}\left(p(y \mid x) \,\|\, p(y)\right)\right)
$$

### 📚 Fréchet Inception Distance (FID)

FID оценивает расстояние между многомерными гауссовыми распределениями признаков реальных и сгенерированных изображений, извлечённых сетью Inception v3. Чем меньше FID, тем ближе распределения.

Формула FID:

$$
  \text{FID} = \Vert \mu_r - \mu_g \Vert^2 + \mathrm{Tr} \left( C_r + C_g - 2 \cdot \left( C_r C_g \right)^{1/2} \right)
$$

### 🧪 Генерация изображений простым VAE на MNIST

Первым этапом примера является скрипт `vae_mnist.py` создания модели, обучения на MNIST в течение 10 эпох и генерации изображений. Сгенерированные изображения затем будем оценивать с точки зрения качества 

```python
import os
import struct
from pathlib import Path
import numpy as np
import tensorflow as tf
from tensorflow.keras import layers, Model
import matplotlib.pyplot as plt

def load_mnist_images(path: Path) -> np.ndarray:
    with open(path, "rb") as f:
        magic, num, rows, cols = struct.unpack(">IIII", f.read(16))
        data = np.frombuffer(f.read(), dtype=np.uint8)
    return data.reshape(num, rows, cols)

# Построение энкодера
# Энкодер преобразует изображение в латентное представление с параметрами распределения: z_mean и z_log_var
def build_encoder(latent_dim=2):
    inputs = layers.Input(shape=(28,28,1)) # Входное изображение 28x28x1
    x = layers.Flatten()(inputs)           # Преобразование в вектор
    x = layers.Dense(128, activation='relu')(x) # Полносвязный слой
    z_mean    = layers.Dense(latent_dim, name='z_mean')(x) # Среднее распределения
    z_log_var = layers.Dense(latent_dim, name='z_log_var')(x) # Логарифм дисперсии

    def sampling(args):
        mean, log_var = args
        eps = tf.random.normal(shape=tf.shape(mean)) # Случайный шум
        return mean + tf.exp(0.5 * log_var) * eps # Репараметризация

    z = layers.Lambda(sampling)([z_mean, z_log_var]) # Сэмплирование латентного вектора
    return Model(inputs, [z_mean, z_log_var, z], name='encoder')

# Построение декодера
# Декодер восстанавливает изображение из латентного пространства.
def build_decoder(latent_dim=2):
    latent_inputs = layers.Input(shape=(latent_dim,)) # Вход — латентный вектор
    x = layers.Dense(128, activation='relu')(latent_inputs) # Полносвязный слой
    x = layers.Dense(28*28, activation='sigmoid')(x) # Выходной слой
    outputs = layers.Reshape((28,28,1))(x) # Возврат к форме изображения
    return Model(latent_inputs, outputs, name='decoder')

class VAE(Model):
    # Инициализация модели VAE с энкодером и декодером. Также создаются трекеры для отслеживания потерь.
    def __init__(self, encoder, decoder, **kwargs):
        super().__init__(**kwargs)
        self.encoder = encoder
        self.decoder = decoder
        self.loss_tracker        = tf.keras.metrics.Mean(name="loss")
        self.recon_loss_tracker  = tf.keras.metrics.Mean(name="recon_loss")
        self.kl_loss_tracker     = tf.keras.metrics.Mean(name="kl_loss")

    # Определение метрик, которые будут логироваться во время обучения.
    @property
    def metrics(self):
        return [self.loss_tracker,
                self.recon_loss_tracker,
                self.kl_loss_tracker]

    # Компиляция модели с заданным оптимизатором.
    def compile(self, optimizer, **kwargs):
        super().compile(**kwargs)
        self.optimizer = optimizer

    # Шаг обучения
    # Проверка, если data — кортеж, извлекается только изображение.
    def train_step(self, data):
        if isinstance(data, tuple):
            data = data[0]

        # Прямой проход: кодирование и декодирование.
        with tf.GradientTape() as tape:
            z_mean, z_log_var, z = self.encoder(data)
            reconstruction      = self.decoder(z)

            # Преобразование изображений в векторы для расчёта потерь.
            x_flat   = tf.reshape(data,        [-1, 28*28])
            rec_flat = tf.reshape(reconstruction, [-1, 28*28])

            # Вычисление потерь реконструкции (насколько хорошо декодер восстановил изображение).
            recon_loss = tf.reduce_mean(
                tf.keras.losses.binary_crossentropy(x_flat, rec_flat)
            ) * 28 * 28

            # Вычисление KL-дивергенции — насколько распределение z отличается от нормального.
            kl_loss = -0.5 * tf.reduce_mean(
                tf.reduce_sum(1 + z_log_var
                              - tf.square(z_mean)
                              - tf.exp(z_log_var),
                              axis=1)
            )

            # Общая потеря — сумма реконструкции и KL.
            total_loss = recon_loss + kl_loss

        # Обновление весов модели.
        grads = tape.gradient(total_loss, self.trainable_weights)
        self.optimizer.apply_gradients(zip(grads, self.trainable_weights))

        # Обновление метрик и возврат значений потерь.
        self.loss_tracker.update_state(total_loss)
        self.recon_loss_tracker.update_state(recon_loss)
        self.kl_loss_tracker.update_state(kl_loss)

        return {
            "loss":       self.loss_tracker.result(),
            "recon_loss": self.recon_loss_tracker.result(),
            "kl_loss":    self.kl_loss_tracker.result(),
        }

def main(epochs=5, output_dir='output'):
    # 1. Загрузка и подготовка данных из локального каталога
    mnist_raw = Path(os.path.expanduser("~/data/MNIST/raw"))
    x_train = load_mnist_images(mnist_raw / "train-images-idx3-ubyte")
    x_train = x_train.astype('float32') / 255.
    x_train = np.expand_dims(x_train, -1)
    #vae, encoder, decoder = build_vae()
    # 2. Построение модели
    latent_dim = 2
    encoder = build_encoder(latent_dim)
    decoder = build_decoder(latent_dim)
    vae     = VAE(encoder, decoder)
    #vae.compile(optimizer='adam')
    # 3. Обучение
    vae.compile(optimizer=tf.keras.optimizers.Adam())
    
    #vae.fit(x_train, x_train, epochs=epochs, batch_size=128)
    vae.fit(x_train,
            epochs=epochs,
            batch_size=128)
    # 4. Сохранение decoder'а сразу после обучения
    os.makedirs(output_dir, exist_ok=True)
    decoder.save(os.path.join(output_dir, 'decoder.h5'))
    print(f"Decoder saved to {output_dir}/decoder.h5")
    # 5. Визуализация и сохранение примеров
    z_sample = np.random.normal(size=(16, 2))
    x_decoded = decoder.predict(z_sample)
    plt.figure(figsize=(4,4))
    for i in range(16):
        plt.subplot(4,4,i+1)
        plt.imshow(x_decoded[i].reshape(28,28), cmap='gray')
        plt.axis('off')
    plt.savefig(f'{output_dir}/vae_mnist.png')

if __name__ == '__main__':
    import argparse
    parser = argparse.ArgumentParser()
    parser.add_argument('--epochs', type=int, default=5)
    parser.add_argument('--output-dir', type=str, default='output')
    args = parser.parse_args()
    main(args.epochs, args.output_dir)

```

**📖 Что происходит в коде**

- `load_mnist_images(path)` — ручной парсер формата IDX: `struct.unpack(">IIII", f.read(16))` читает 4 числа заголовка (magic, количество изображений, высота, ширина), дальше `np.frombuffer(..., dtype=np.uint8)` — «сырые» пиксели, приводимые к форме `(num, 28, 28)`.
- `build_encoder(latent_dim)` — энкодер: `Flatten` (28×28 → вектор 784) → `Dense(128, relu)` → две параллельные головы `z_mean` (среднее) и `z_log_var` (логарифм дисперсии) — параметры гауссова распределения в латентном пространстве. Функция `sampling` реализует **трюк репараметризации**: `z = mean + exp(0.5·log_var)·eps`, где `eps ~ N(0,1)` — благодаря ему «случайный» шаг становится дифференцируемым и градиент проходит через сэмплирование. Модель возвращает и головы, и сэмплированный `z`.
- `build_decoder(latent_dim)` — декодер: латентный вектор → `Dense(128, relu)` → `Dense(784, sigmoid)` → `Reshape(28, 28, 1)`; `sigmoid` на выходе, т.к. пиксели нормализованы в [0, 1].
- Класс `VAE(Model)` — обучение через свой `train_step`: `recon_loss` — бинарная энтропия между исходным и восстановленным изображением, умноженная на 784 (сумма по пикселям); `kl_loss` — KL-дивергенция между распределением `N(z_mean, exp(z_log_var))` и стандартным нормальным `N(0, 1)` в замкнутом виде (удерживает латентное пространство близким к `N(0, 1)`); `total_loss = recon_loss + kl_loss`, градиенты считает `GradientTape`, веса обновляет `optimizer`. Трекеры `loss/recon_loss/kl_loss` логгируются при каждом шаге.
- `main(epochs, output_dir)`: MNIST читается из `~/data/MNIST/raw`, нормализуется в [0, 1] и дополняется каналом. Строится модель с `latent_dim = 2`. `vae.fit(x_train, ...)` — цель обучения здесь само изображение (автокодирование: VAE учится воспроизводить вход). После обучения сохраняется **только декодер** `decoder.h5` — для генерации достаточно именно его: латентный вектор можно сэмплировать напрямую из `N(0, 1)`, минуя энкодер. Затем 16 случайных точек `N(0, 1)` декодируются в сетку 4×4 и сохраняются в `vae_mnist.png`.
- Аргументы командной строки: `--epochs` (по умолчанию в коде 5 — командой запуска задаётся 10), `--output-dir` (папка результата).

Запуск из командной строки:

```bash
python vae_mnist.py --epochs 10 --output-dir output
```

Аргументы: `--epochs 10` — число эпох обучения (в коде по умолчанию 5, командой поднимаем до 10); `--output-dir output` — папка, куда сохраняются `decoder.h5` и `vae_mnist.png`.

После запуска в каталоге `output` будут созданы файл `vae_mnist.png` с примерами изображений и файл модели `decoder.h5`, которая эти изображения генерирует.

### 🧪 Создание множества изображений с использованием сохраненной модели

Для объективной оценки качества генерации одного изображения недостаточно — необходима т.н. репрезентативная выборка. 

Для ее создания используем следующий скрипт `generate_samples.py`

```python
import argparse
import os
import numpy as np
from tensorflow.keras.models import load_model
import imageio

def main(decoder_path="output/decoder.h5",
         output_dir="images",
         n_samples=2000,
         latent_dim=2):
    os.makedirs(output_dir, exist_ok=True)
    decoder = load_model(decoder_path)

    # Берём N точек из N(0,1)
    z = np.random.normal(size=(n_samples, latent_dim))
    imgs = decoder.predict(z)  # shape (n_samples, 28,28,1)

    # Сохраняем
    for i, img in enumerate(imgs):
        # Масштабируем 0–1 → 0–255 и приводим к uint8
        arr = (img[:, :, 0] * 255).astype(np.uint8)
        imageio.imwrite(os.path.join(output_dir, f"sample_{i:05d}.png"), arr)

    print(f"Saved {n_samples} images to {output_dir}")

if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--decoder", type=str, default="output/decoder.h5")
    parser.add_argument("--output-dir", type=str, default="images")
    parser.add_argument("--n-samples", type=int, default=2000)
    parser.add_argument("--latent-dim", type=int, default=2)
    args = parser.parse_args()
    main(args.decoder, args.output_dir, args.n_samples, args.latent_dim)
```

**📖 Что происходит в коде**

- `load_model(decoder_path)` — загружает сохранённый после обучения **декодер** (именно он, а не весь VAE — для генерации достаточно).
- `z = np.random.normal(size=(n_samples, latent_dim))` — 2000 случайных точек из стандартного нормального `N(0, 1)` в латентном пространстве; именно из таких точек «вытягиваются» новые изображения.
- `decoder.predict(z)` — декодирует все точки в изображения формы `(2000, 28, 28, 1)`.
- Цикл сохраняет каждое изображение: `(img[:, :, 0] * 255).astype(np.uint8)` — из [0, 1] в 0–255 (формат PNG), имя — `sample_00000.png`, `sample_00001.png`, …, `sample_01999.png`.

Почему именно 2000 штук: IS и FID — **статистические** метрики, они оценивают распределение изображений целиком, а не одно изображение; на единичном образце их посчитать невозможно, нужна репрезентативная выборка.

Запуск скрипта максимально прост:

```bash
python generate_samples.py --decoder output/decoder.h5 --output-dir images
```

Аргументы: `--decoder output/decoder.h5` — путь к сохранённому декодеру; `--output-dir images` — папка выборки; по умолчанию `--n-samples 2000` и `--latent-dim 2` (обязан совпадать с размерностью, с которой обучался VAE).

В результате, в папке images должны появиться 2000 изображений, что можно считать достаточной выборкой для качественной оценки моделей компьютерного зрения.

### 🧪 Вычисление IS и FID для сгенерированных изображений

И теперь мы готовы к расчету метрик — используем следующий скрипт `eval_metrics.py`

```python
import os
import struct
import glob
from pathlib import Path
import numpy as np
import tensorflow as tf
from tensorflow.keras.applications.inception_v3 import InceptionV3, preprocess_input
from scipy.linalg import sqrtm
from PIL import Image

# Используем общий каталог Keras, предзагруженный в образе JupyterHub.
os.environ["KERAS_HOME"] = "/hf-cache/keras"

def load_mnist_images(path: Path) -> np.ndarray:
    with open(path, "rb") as f:
        magic, num, rows, cols = struct.unpack(">IIII", f.read(16))
        data = np.frombuffer(f.read(), dtype=np.uint8)
    return data.reshape(num, rows, cols)

def to_inception_batch(images, size=(299, 299)):
    out = []
    for img in images:
        rgb = Image.fromarray(np.asarray(img, dtype=np.uint8), mode="L").convert("RGB").resize(size)
        out.append(np.array(rgb))
    return np.array(out)

def load_real_mnist(mnist_root="~/data/MNIST", size=(299, 299), max_images=1000):
    raw_path = Path(os.path.expanduser(mnist_root)) / "raw" / "train-images-idx3-ubyte"
    imgs = load_mnist_images(raw_path)[:max_images]
    return to_inception_batch(imgs, size=size)

def load_generated_images(path, size=(299, 299), max_images=1000):
    files = sorted(glob.glob(os.path.join(path, "sample_*.png")))[:max_images]
    if not files:
        raise FileNotFoundError(f"Не найдено файлов sample_*.png в каталоге: {path}")
    imgs = []
    for f in files:
        img = Image.open(f).convert("RGB").resize(size)
        imgs.append(np.array(img))
    return np.array(imgs)

def calculate_inception_score(images, splits=10, batch_size=32):
    model = InceptionV3(include_top=True, weights='imagenet', pooling='avg')
    images = preprocess_input(images.astype('float32'))
    preds = model.predict(images, batch_size=batch_size)
    p_y = np.mean(preds, axis=0)
    scores = []
    N = preds.shape[0] // splits
    for i in range(splits):
        part = preds[i*N:(i+1)*N]
        kl = part * (np.log(part+1e-10) - np.log(p_y+1e-10))
        scores.append(np.exp(np.sum(kl, axis=1).mean()))
    return float(np.mean(scores)), float(np.std(scores))

def calculate_fid(real, gen, batch_size=32):
    model = InceptionV3(include_top=False, weights='imagenet', pooling='avg')
    act1 = model.predict(preprocess_input(real.astype('float32')), batch_size=batch_size)
    act2 = model.predict(preprocess_input(gen.astype('float32')), batch_size=batch_size)
    mu1, sigma1 = act1.mean(axis=0), np.cov(act1, rowvar=False)
    mu2, sigma2 = act2.mean(axis=0), np.cov(act2, rowvar=False)
    covmean = sqrtm(sigma1.dot(sigma2))
    if np.iscomplexobj(covmean):
        covmean = covmean.real
    return np.sum((mu1 - mu2)**2) + np.trace(sigma1 + sigma2 - 2*covmean)

def main(real_dir, gen_dir):
    real = load_real_mnist(real_dir)
    gen = load_generated_images(gen_dir)
    is_mean, is_std = calculate_inception_score(gen)
    fid_value = calculate_fid(real, gen)
    print(f'Inception Score: {is_mean:.3f} ± {is_std:.3f}')
    print(f'FID: {fid_value:.3f}')

if __name__ == '__main__':
    import argparse
    parser = argparse.ArgumentParser()
    parser.add_argument('--real', type=str, default=os.path.expanduser('~/data/MNIST'))
    parser.add_argument('--gen', type=str, default='images')
    args = parser.parse_args()
    main(args.real, args.gen)
```

**📖 Что происходит в коде**

- `os.environ["KERAS_HOME"] = "/hf-cache/keras"` — веса Inception v3 уже предзагружены в образе JupyterHub в этот каталог: скачивать их из интернета не нужно, скрипт работает офлайн.
- `to_inception_batch(images, size=(299, 299))` — Inception v3 ожидает цветные изображения 299×299: каждое изображение приводится к режиму `"L"`, переводится в RGB (`convert("RGB")` — одинаковое значение на три канала) и масштабируется до 299×299.
- `load_real_mnist` — первые 1000 настоящих изображений из `~/data/MNIST/raw/...` (референс для FID).
- `load_generated_images` — первые 1000 файлов `sample_*.png` из папки сгенерированной выборки.
- `calculate_inception_score(images, splits=10)`:
  - `InceptionV3(include_top=True, ...)` — модель **с** классификационной головой: по каждому сгенерированному изображению она выдаёт вероятности 1000 классов ImageNet, то есть распределение `p(y|x)`;
  - `p_y = np.mean(preds, axis=0)` — среднее распределение `p(y)`;
  - предсказания разбиваются на 10 частей (`splits`) для устойчивости оценки: в каждой части считается KL-дивергенция `p(y|x) || p(y)` (слагаемое `+1e-10` защищает логарифм от нуля), усредняется по образцам и возводится в `exp`; итоговый IS — среднее по частям, плюс стандартное отклонение;
  - смысл: высокий IS, когда Inception «уверенно» классифицирует каждый сгенерированный образ (низкая энтропия `p(y|x)`) — т.е. изображение похоже на реальный объект, — и при этом образы разнообразны (высокая энтропия `p(y)`).
- `calculate_fid(real, gen)`:
  - `InceptionV3(include_top=False, ...)` — модель **без** классификационной головы: извлекает признак 2048-мерного вектора для каждого изображения;
  - для реальных и сгенерированных выборок считаются среднее `mu` и ковариационная матрица `sigma` (`np.cov(..., rowvar=False)`);
  - `sqrtm(sigma1 · sigma2)` — матричная квадратная корень; если результат комплексный, берётся вещественная часть;
  - `FID = ||mu1 − mu2||² + Tr(sigma1 + sigma2 − 2·(sigma1·sigma2)^{1/2})` — расстояние между двумя гауссовыми распределениями признаков; меньше FID — распределения ближе.
- `main(real_dir, gen_dir)` — загружает обе выборки, считает и печатает `Inception Score: X ± Y` и `FID: Z`.
- Аргументы командной строки: `--real` — каталог реальных MNIST (по умолчанию `~/data/MNIST`); `--gen` — папка сгенерированных изображений (по умолчанию `images`).

Запуск данного скрипта:

```bash
python eval_metrics.py --real ~/data/MNIST --gen images
```

Аргументы: `--real ~/data/MNIST` — каталог реальных MNIST (референс для FID); `--gen images` — папка с сгенерированной выборкой из предыдущего шага.

**📌 Ожидаемый результат**
Две строки вывода: `Inception Score: ... ± ...` и `FID: ...`. Для простой 2D-VAE, обученной 10 эпох, значения будут скромными (IS — обычно единицы, FID — десятки–сотни): модель намеренно простая и не оптимизирована под качество. Точные цифры зависят от случайной инициализации и не воспроизводятся в точности от запуска к запуску.
