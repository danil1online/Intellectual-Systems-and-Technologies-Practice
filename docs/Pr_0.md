# Практическая работа №0: Предварительная настройка учебного комплекса

> 📌 **Для запуска автоматической оценки работы выполните финальное действие (описано ниже).**

## Цель работы
Настроить рабочее окружение: регистрация в учебной системе, настройка SSH-ключей, первый вход в JupyterHub.

---

## 1. Регистрация

1. Откройте **JupyterHub**: `http://<server-ip>:8000`
2. Нажмите **Sign up** (кнопка регистрации на странице входа)
3. Заполните форму:
   - **Username**: `student_<группа>_<номер>` (например: `student_pia_01`)
   - **Email**: ваш студенческий email
   - **Password**: придумайте надёжный пароль (запомните его!)
4. Нажмите **Register**

> ✅ Ваша учётная запись создана. С этими же данными вы можете войти в GitLab и JupyterHub.

## 3. SSH-ключ для GitLab

SSH-ключ автоматически создаётся при первом входе в JupyterHub. Если ключ уже есть, пропустите Шаг 1 и перейдите к Шагу 2.

### Шаг 1: Проверка SSH-ключа

Откройте **JupyterHub**: `http://<server-ip>:8000`, войдите и создайте терминал (**File → New → Terminal**).

Проверьте, есть ли SSH-ключ:
```bash
ls ~/.ssh/id_ed25519.pub
```

Если файл существует — ключ уже создан. Переходите к Шагу 2.

Если файла нет — создайте ключ:
```bash
ssh-keygen -t ed25519 -C "student_<группа>_<номер>@academic"
```
Нажмите Enter на все вопросы (без passphrase).

### Шаг 2: Получение публичного ключа

```bash
cat ~/.ssh/id_ed25519.pub
```

Вы увидите строку вида:
```
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAA... student_pia_01@academic
```

**Скопируйте всю строку!**

### Шаг 3: Добавление ключа в GitLab

1. Откройте **GitLab**: `http://<server-ip>:80`
2. Войдите под своим логином и паролем
3. Перейдите: **Settings (меню слева) → SSH Keys**
4. Вставьте скопированный ключ в поле **Key**
5. Нажмите **Add key**

> 🔑 Ключ добавлен! Теперь вы можете работать с Git по SSH.

## 5. Доступ к методическим материалам

Все методические материалы (`.md` файлы) доступны в GitLab:

**Способ 1: Через веб-интерфейс GitLab**
1. Откройте **GitLab**: `http://<server-ip>:80`
2. Найдите репозиторий с учебными материалами (уточните у преподавателя)
3. Откройте любой файл `.md` — он отобразится в отформатированном виде

**Способ 2: Через терминал JupyterLab**
```bash
git clone --depth 1 http://<server-ip>/<username>/project.git
cd project/docs
ls -la
```

## 6. Загрузка отчёта

1. В терминале JupyterLab клонируйте ваш репозиторий отчётов:
```bash
git clone -p 2222 git@gitlab.<server-ip>:<username>/reports_<группа>_<номер>.git
cd reports_<группа>_<номер>
```
2. Сохраните отчёт как `Pr_0_<группа>_<номер>.md`
3. Скопируйте в репозиторий и отправьте:
```bash
cp Pr_0_<группа>_<номер>.md .
git add .
git commit -m "Pr_0 report"
git push
```

## Отчёт по работе

1. Сделайте скриншоты:
   - Ваша учётная запись в GitLab (Settings → Account)
   - Ваш SSH-ключ в GitLab (Settings → SSH Keys)
   - Терминал JupyterLab с результатом `cat ~/.ssh/id_ed25519.pub`
2. Сохраните отчёт как `Pr_0_<группа>_<номер>.md` в формате Markdown
3. Загрузите файл `.md` в репозиторий **reports** в GitLab

**Финальное действие:**

Для запуска автоматической оценки создайте триггер-файл и отправьте его в репозиторий:

```bash
touch .grade-trigger
git add .grade-trigger
git commit -m "Grade trigger"
git push
```

> ⏳ Оценка запустится автоматически в GitLab CI. Результат появится в разделе **CI/CD → Pipelines**.
