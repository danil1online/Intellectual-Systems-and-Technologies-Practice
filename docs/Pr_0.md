## 3. SSH-ключ для GitLab

SSH-ключ автоматически создаётся при первом входе в JupyterHub.

### Шаг 1: Проверка SSH-ключа

Откройте **JupyterHub**: `http://<server-ip>:8000`, войдите и создайте терминал.

<img src="./images/2026-08-13_01-39-03.png" width="50%">

Проверьте, есть ли SSH-ключ:
```bash
ls ~/.ssh/id_ed25519.pub
```
<img src="./images/2026-08-13_01-42-44.png" width="50%">
Если файл существует — ключ уже создан. Переходите к Шагу 2.

Если файла нет — создайте ключ:
```bash
ssh-keygen -t ed25519 -C "student_<группа>_<номер>@academic-platform"
```
Нажмите Enter на все вопросы (без passphrase).

### Шаг 2: Получение публичного ключа

```bash
cat ~/.ssh/id_ed25519.pub
```

Вы увидите строку вида:
```
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAA... student_pia_01@academic-platform
```

**Скопируйте всю строку!**

### Шаг 3: Добавление ключа в GitLab

1. Откройте **GitLab**: `http://<server-ip>:80`
   
2. Войдите под своим логином и паролем

3. Кликните на аватарку профиля в правом верхнем углу GitLab. Откройте раздел Preferences (Настройки). 
<img src="./images/2026-08-13_01-41-16.png" width="50%">

4. Найдите в левом меню пункт ***Access -> SSH Keys***.

<img src="./images/2026-08-13_01-41-45.png" width="50%">

5. Нажмите ***Add new key***

<img src="./images/2026-08-13_01-42-09.png" width="50%">

6. Вставьте скопированный текст публичного ключа в большое текстовое поле Key.

<img src="./images/2026-08-13_01-43-49.png" width="50%">

7. Задайте при необходимости название (Title) и срок действия (Expiration date).

8. Нажмите зеленую кнопку Add key.

> 🔑 Ключ добавлен! Теперь вы можете работать с Git по SSH.

<img src="./images/2026-08-13_01-44-48.png" width="50%">

9. Перейдите в клонированный репозиторий в GitLab. В нем же есть и методические материалы (в каталоге `docs/`).
    
   - Нажмите справа вверху иконку своего профиля и затем имя. Затем выберете проект, который Вы только что скопировали в свою учетную запись.
     
   <img src="./images/2026-08-13_01-52-07.png" width="50%">
   
   - Появится окно репозитория. Нужно нажать кнопку `Code` и потом нажать кнопку копирования рядом с надписью `Clone with SSH`.
     
   <img src="./images/2026-08-13_02-00-26.png" width="50%">
   
10. Перейдите в терминал Jupyter и клонируйте внутрь него скопированный к себе в GitLab репозиторий командой. В случае вопросов ответьте `yes` (нужно напечатать).

```bash
git clone <Тут вставьте адрес, который Вы скопировали в предыдущем пункте вида ssh://git@<server-ip>:2222/testuser/project.git>
```

<img src="./images/2026-08-13_02-04-35.png" width="50%">

11. Войдите в левом окне в новый каталог `project`, закройте открытое окно Launcher'а и запустите новое, а в нем - новый терминал. Именно в таком окне Вы будете начинать каждую практическую работу.
    
<img src="./images/2026-08-13_02-10-22.png" width="50%">

12. Сообщите Git свои данные, для этого введите команды (подставьте свои "you@example.com" и "Your Name")
    
```bash
git config --global user.email "you@example.com"
git config --global user.name "Your Name"
```

<img src="./images/2026-08-13_02-23-02.png" width="50%">

## 6. Отчёт по работе

1. В JupyterLab слева войдите в каталог `reports`

2. Создайте новый каталог `Pr_0`.

<img src="./images/2026-08-13_14-11-03.png" width="50%">

3. Cоздайте новое окно Launcher'а JupyterLab и в нем выберите `MarkDown file`. Работа с данным форматом документов описана в [отдельном файле](MD_Instructions.md)

<img src="./images/2026-08-13_14-11-53.png" width="50%">

4. Опишите в файле ход выполнения данной работы.

5. Выберите `File` (слева вверху) - `Save Markdown File`

6. Сохраните отчёт как `Pr_0_<группа>_<номер>.md`

<img src="./images/2026-08-13_14-12-15.png" width="50%">

7. Отправьте репозиторий на сервер. Вернитесь в открытое окно терминала (обратите внимание: слева от поля ввода указан путь, д.б. `xxxxx@xxxxxx:~/project$`, т.е. терминал работает в каталоге `project`).

8. Наберите

```bash
git add .
git commit -m "Pr_0 report"
git push
```

<img src="./images/2026-08-13_02-23-46.png" width="50%">

9. Проверьте, что файл `Pr_0 report` появился в Вашем репозитории

<img src="./images/2026-08-13_14-22-35.png" width="50%">

**Финальное действие:**

Для запуска автоматической оценки создайте триггер-файл и отправьте его в репозиторий:

```bash
cd ~/project
touch ./reports/Pr_0/.grade-trigger
git add ./reports/Pr_0/.grade-trigger
git commit -m "Grade trigger"
git push
```
<img src="./images/2026-08-13_14-25-48.png" width="50%">
> ⏳ Оценка запустится автоматически в GitLab CI. Результат появится в разделе **CI/CD → Pipelines**.
