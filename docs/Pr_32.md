## 📚 Краткая теоретическая информация

### Property Graph и язык Cypher
Граф знаний — это набор **узлов** (сущности со свойствами) и **направленных рёбер** (типизированные отношения). Язык запросов **Cypher** описывает подграф-паттерн: узел `(n:Label {prop: value})`, ребро `(a)-[:REL_TYPE]->(b)`; операторы `MATCH`, `CREATE`/`MERGE`, `WHERE`, `RETURN`.

### GraphRAG и Multi-hop Reasoning
GraphRAG заменяет (или дополняет) векторный поиск обходом графа: вопрос транслируется в Cypher, Neo4j возвращает подграф/таблицу, LLM синтезирует ответ. Ключевое преимущество — **multi-hop reasoning**: вопросы, требующие последовательных переходов по цепочке связей (A→B→C), которые классический векторный RAG решить не может, поскольку ни один текстовый чанк не содержит готового ответа.

2. Выполните: `MATCH (n) RETURN labels(n) AS label, count(*)` — убедитесь, что узлы и связи на месте.
3. Визуализируйте граф: `MATCH (n) OPTIONAL MATCH (n)-[r]-(m) RETURN n, r, m LIMIT 50`.

### Шаг 1. Размещение компонентов GraphRAG
Создайте flow `Практическая 32 - GraphRAG Neo4j`. Добавьте: **Chat Input**, **Chat Output**, **Prompt (Text-to-Cypher)**, **OpenAI Model 1**, компонент **Neo4j Cypher**, **Prompt (Graph Synthesizer)**, **OpenAI Model 2**.

### Шаг 3. Подключение к Neo4j
Параметры компонента **Neo4j Cypher**: `URI = bolt://neo4j:7687`, `Username = neo4j`, `Password = <выданный пароль>`. Проверьте соединение запросом `MATCH (n) RETURN count(n)`.

### Шаг 4. Генерация Cypher и синтез ответа
Шаблон **Prompt (Text-to-Cypher)** — укажите схему графа (узлы `Student`, `Teacher`, `Course`, `Department` и связи `TEACHES`, `ENROLLED_IN`, `MENTORED_BY`, `BELONGS_TO`) и инструкцию выдавать только чистый Cypher.

Шаблон **Prompt (Graph Synthesizer)**:

```text
System: Сформируй ответ пользователю на понятном русском языке на основе результатов запроса к графовой БД.

ВОПРОС: {user_query}
CYPER: {cypher_query}
РЕЗУЛЬТАТ ГРАФА: {graph_result}
ОТВЕТ:
```

Цепочка: Chat Input → Prompt (Cypher) → Model 1 → Neo4j Cypher → Prompt (Synthesizer) → Model 2 → Chat Output.

### Шаг 5. Тестирование в Playground
1. Мульти-хоп вопрос: «Кто является научным руководителем студента, записанного на курс Графовые базы данных?» — проверьте сгенерированный Cypher и корректность ответа.
